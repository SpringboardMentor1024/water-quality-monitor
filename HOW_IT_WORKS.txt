WATER QUALITY MONITOR - HOW IT WORKS
=====================================

SYSTEM OVERVIEW:
- Backend (FastAPI): Runs on http://localhost:8000
- Frontend (React): Runs on http://localhost:3000
- Database: SQLite (water_quality.db)

HOW FRONTEND CONNECTS TO BACKEND:
=================================

1. FRONTEND MAKES API CALLS:
   - When you open a page, React components call backend APIs
   - Example: AlertsPage calls http://localhost:8000/api/alerts
   - Data flows: Backend Database → API → Frontend Display

2. AUTHENTICATION FLOW:
   - Login page sends credentials to /api/auth/login
   - Backend returns JWT token
   - Token stored in localStorage
   - All future API calls include this token

3. DATA FLOW EXAMPLE:
   Frontend Component → API Call → Backend Endpoint → Database → Response → Frontend Display
